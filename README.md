# 🧩 Programming Basics

A collection of small beginner-friendly programs created while learning **C and Python** and practicing fundamental programming concepts.

These projects focus on building programming logic through simple games and pattern-based programs.

## 📂 Programs Included

### ❌⭕ Tic-Tac-Toe

A simple console-based **Tic-Tac-Toe game** for two players.

**Language:** C

**Concepts practiced:**

* Arrays
* Loops
* Conditional statements
* Functions
* User input
* Basic game logic

### ✊ Rock Paper Scissors

A console-based **Rock Paper Scissors game** where the player competes against the computer.

**Language:** Python

**Concepts practiced:**

* Conditional statements
* Loops
* User input
* Random number generation
* Basic game logic

### ❤️ Heart Pattern

A simple Python program that prints a **heart-shaped pattern** using characters and loops.

**Language:** Python

**Concepts practiced:**

* Nested loops
* Pattern printing
* Iteration
* Console formatting

## 🛠️ Technologies

* **C**
* **Python**
* GCC / Standard C Compiler
* Python 3

## 🚀 Running the Programs

### C Program

Compile the Tic-Tac-Toe program using GCC:

```bash
gcc tic_tac_toe.c -o tic_tac_toe
```

Run it:

```bash
./tic_tac_toe
```

### Python Programs

Run either Python program with:

```bash
python filename.py
```

Make sure **Python 3** is installed on your system.
